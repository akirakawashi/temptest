# temptest — стенд распознавания речи

Три независимых теста на одном наборе из 100 аудиозаписей и одной GPU:

| Тест | Команда из папки `temptest` | Что измеряется |
|---|---|---|
| Whisper large-v3 | `bash benchmark/run.sh ../audio` | весь HTTP-запрос к собственному серверу |
| GigaAM v3 через TensorRT | `bash benchmark/run-gigaam-trt.sh ../audio` | поиск речи, распознавание, паузы |
| T-one через TensorRT | `bash benchmark/run-tone-trt.sh ../audio` | потоковое распознавание всей записи |

Тесты запускаются по одному: общий замок не даёт стартовать двум сразу. Голоса,
эмоции и языковая модель в стенде не запускаются.

Рабочие контейнеры и API не используются. Тестовый Whisper берётся из того же
закреплённого CUDA-образа, который указан в конфигурации рабочего сервиса.
Кеши, сети и контейнеры принадлежат стенду. GPU общая с продом; посторонняя
нагрузка влияет на время.

## Запуск

Запуск выполняет владелец. Если рядом с `temptest` лежит папка `audio`:

```bash
cp -n benchmark/server.env.example .env
BENCH_GPU=0 BENCH_GPU_MIN_FREE_MIB=12288 BENCH_GPU_MAX_UTIL=100 \
  bash benchmark/run.sh ../audio
```

Вывод сразу виден в терминале и сохраняется в журнал. Ключ рабочего Whisper
не нужен. Значения 12288 МиБ и 100% предназначены для прогона на общем
загруженном сервере. Без явных параметров Whisper требует 16 ГиБ свободной VRAM
и загрузку ≤10%; резерв свободной VRAM контролируется весь прогон.

Нужны Linux x86-64, Docker/Compose, NVIDIA Container Toolkit, Bash, flock,
tar и timeout. Python и пакеты устанавливаются внутри образов; `apt` в сборках
отсутствует. Интернет нужен для образов, Python-пакетов и предварительной
загрузки весов. Загрузчики не видят аудио и GPU; обработка записей проходит
во внутренних сетях стенда.

## Результаты

Каждый запуск создаёт свою папку в `benchmark-results/`: подробный русский
журнал, тексты, ошибки, параметры, фактические версии, CSV времён и нагрузки GPU,
`отчёт.html`. Отчёт обновляется после каждой записи. `диагностика.tar.gz`
содержит результаты и логи, без аудио, моделей, `.env` и ключей.

После завершения или ошибки контейнеры стенда останавливаются и сохраняются
для просмотра логов. Временные WAV удаляются; исходные записи, результаты
и кеши весов остаются. Автоматического удаления контейнеров нет.

Загрузка моделей, прогрев и подготовка общего WAV исключены из замеров.
Скорость не является оценкой точности.
