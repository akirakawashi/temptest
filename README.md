# temptest — рабочий Whisper API и полный цикл GigaAM

Файловый стенд для сравнения 100 записей на GPU-сервере. Сначала весь корпус
отправляется в уже работающий Whisper, затем проходит отдельный полный
конвейер GigaAM: VAD, ASR, собеседники, эмоции и локальная GigaChat через Ollama.

Рабочие Whisper, model-proxy и vLLM не перезапускаются и не перенастраиваются.
Один аудиозапрос за раз, пауза минимум 5 секунд, повторов нет. Ошибка прекращает
прогон. GigaAM проверяет свободные ресурсы и использует только свои контейнеры.

## Запуск

```bash
git clone https://github.com/akirakawashi/temptest.git
cd temptest
cp -n benchmark/server.env.example .env
chmod 600 .env
```

В `.env` задайте адрес существующего Whisper и выданный клиентский ключ
model-proxy в `WHISPER_API_KEY`. Аудио хранится отдельно от репозитория.

```bash
BENCH_GPU=0 bash benchmark/run.sh /srv/speech-test/audio
```

По умолчанию ожидаются ровно 100 файлов. Нужны Linux x86-64, Docker/Compose,
доступ NVIDIA GPU из Docker и интернет для подготовки образов и весов.
Перед стартом требуется минимум 16 ГиБ свободной VRAM, загрузка GPU ≤10%,
20 ГиБ доступной RAM и 32 ГиБ свободного диска. Во время GigaAM резерв VRAM
контролируется; при нехватке останавливается только стенд. На общей GPU
выберите окно без посторонних вычислений.

## Результаты

`benchmark-results/<дата-ID>/` содержит подробный русский журнал, тексты и
сегменты, времена, условия, мониторинг GPU, CSV, самодостаточный HTML с графиками
и SVG. `диагностика.tar.gz` можно передать для разбора: в нём есть тексты
разговоров, но нет аудио, моделей или ключа API. Подготовленные WAV удаляются.

Whisper измеряется как полный HTTP-запрос, включая передачу и очередь.
У GigaAM отдельно измеряются полный цикл и сумма ASR-вызовов. Скорость не
является оценкой точности; времена этапов GigaAM могут пересекаться.

- [Подробная инструкция для сервера](benchmark/SERVER.md)
- [Устройство стенда, таймеры и защиты](benchmark/README.md)

Кеши и результаты остаются локальными и исключены из Git и Docker build.
Источником полного конвейера служит код речевого монитора GigaAM в `app/`.
