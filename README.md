# temptest — отдельный Whisper и полный цикл GigaAM

Стенд последовательно сравнивает 100 аудиозаписей на выбранной GPU:
свой Whisper large-v3 → остановка тестового Whisper → свой полный
GigaAM (VAD, ASR, собеседники, эмоции, локальная GigaChat через Ollama).

Рабочие контейнеры и API не используются. Тестовый Whisper берётся из того же
закреплённого CUDA-образа, который указан в конфигурации рабочего сервиса.
Его кеш, сеть и контейнер принадлежат стенду. GPU общая с продом; посторонняя
нагрузка влияет на время. Тестовые модели работают последовательно.

## Запуск

Запуск выполняет владелец. Из папки `temptest`, если рядом находится `audio`:

```bash
cp -n benchmark/server.env.example .env
BENCH_GPU=0 BENCH_GPU_MIN_FREE_MIB=12288 BENCH_GPU_MAX_UTIL=100 \
  bash benchmark/run.sh ../audio
```

Вывод сразу виден в терминале и сохраняется в журнал. Ключ рабочего Whisper
не нужен; прежние `WHISPER_API_BASE_URL`/`WHISPER_API_KEY` в `.env` игнорируются.
Значения 12288 МиБ и 100% предназначены для прогона на общем загруженном сервере.
Без явных параметров действуют минимальные 16 ГиБ VRAM и загрузка ≤10%.
Резерв свободной VRAM 4 ГиБ контролируется в обеих фазах.

Нужны Linux x86-64, Docker/Compose, NVIDIA Container Toolkit, Bash, flock,
tar и timeout. Python и пакеты устанавливаются внутри образов. Оба образа
используют готовую CUDA-базу Whisper; `apt` в их сборках отсутствует.
Интернет нужен для образов, Python-пакетов и предварительной загрузки весов.
Загрузка весов идёт через сеть сервера (`host`). Эти загрузчики
не видят аудио и GPU. Обработка записей проходит во внутренних сетях стенда;
Ollama для скачивания слушает только `127.0.0.1:11435`.

## Результаты

Одна папка `benchmark-results/<дата-ID>/` содержит подробный русский журнал,
тексты и сегменты обеих систем, ошибки, параметры, фактические версии, CSV
времён и нагрузки GPU, HTML с графиками и SVG. Графики обновляются после
каждой записи. `диагностика.tar.gz` содержит результаты и логи, без аудио,
моделей, `.env` и ключей.

После завершения или ошибки контейнеры стенда останавливаются и сохраняются
вместе с сетями проекта `speech-comparison`. Временные WAV удаляются;
исходные записи, результаты и кеши весов сохраняются. Автоматического удаления
контейнеров нет. Команды управления указывают собственный Compose-проект.

Whisper измеряется как полный HTTP-запрос после прогрева. У GigaAM измеряются
полный цикл, отдельно сумма ASR-вызовов и остальные этапы. Загрузка моделей,
прогрев и подготовка общего WAV исключены из основных таймеров. Скорость
не является оценкой точности.
